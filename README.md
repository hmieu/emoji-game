# Emoji → Emoticon

A tiny personality game: match the emoji to the old-school emoticon and collect points.

## How to play

1. Look at the emoji.
2. Type the matching old-school emoticon.
3. Press **check** or hit **Enter**.
4. Get a point for a correct answer.

## Built with

- HTML
- CSS
- JavaScript

This project was originally part of my personal portfolio and was separated into its own project for GitHub.
